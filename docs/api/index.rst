API reference
=============

These public objects are imported from ``pybsp``. Signatures and methods below
come from the installed library. Internal ``_native`` objects are implementation
details. Users should construct ``Formula`` and ``SolverOptions`` instead.

.. toctree::
   :maxdepth: 1

   datasets
   batch
   solver

Compatibility experiment tools remain available through ``bsp-grid``,
``bsp-plot`` and ``bsp-label``. The native API does not change those CLI interfaces.
